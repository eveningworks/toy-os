# screenshots/

**Only `readme/` lives here**: the two images `README.md` embeds, a
maintained asset -- retake them in place when the desktop changes enough
that they misrepresent it.

Screenshots are a testing tool, not evidence to keep: take them into a
scratch directory outside the repo. For evidence, `docs/gui-guidelines.md`
asks for pixel values with a control point (`tools/pixel_probe.py`) and a
pass/fail table from `tools/gui_regress.py`.

The testing passes saved here until 2026-08-15 -- dated folders
`2026-08-10/` to `2026-08-15/` and the early `v0.2.0/` to `v0.7.0/` --
were removed on 2026-10-05, before the repository went public. Docs that
name one of those files (`docs/decisions/gui.md`, `docs/roadmap-details.md`)
mean it as it was at 1927a61b: `git show 1927a61b:screenshots/<path>`.
