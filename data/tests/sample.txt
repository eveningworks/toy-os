0003  Every line begins with its own number, four digits wide. That is
0004  the whole point: moving identical content is pixel-identical, so a
0005  scroll test over repeated lines cannot tell a working scroll from a
0006  dead one. A capture of any part of this file can be placed exactly.
0007
0008  It is also deliberately awkward, in the ways text handling breaks:
0009  a line longer than any terminal is wide, a line of exactly 80
0010  columns, trailing spaces, a tab, an empty line, and a last line
0011  with no newline after it. Read the tail of this file before
0012  assuming what it ends with.
